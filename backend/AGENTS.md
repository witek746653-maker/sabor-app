# Sabor-app — backend (Flask API)

## API и маршруты
- Backend на Flask; API эндпоинты держать под `/api/*`.
- Запросы в продакшене — same-origin; избегать широких CORS-настроек (если CORS уже есть, держать минимальным и безопасным).

## Аутентификация/авторизация
- Auth cookie-based через Flask-Login: не ломать session/remember cookies.
- Любые эндпоинты, которые модифицируют данные, должны требовать аутентификацию и проверку ролей.

## База данных
- SQLite через SQLAlchemy.
- При изменениях схемы — минимальные правки и безопасные шаги апгрейда.

## Ошибки
- Возвращать согласованный JSON-формат ошибок для фронтенда: `{ "error": "...", "message": "..." }`.
