# Sabor-app — frontend (React + Router + Tailwind)

## Код и структура
- Держать код простым и читаемым.
- Новые страницы добавлять в `frontend/src/pages/`.
- Переиспользуемые компоненты — в `frontend/src/components/`.
- Роутинг поддерживать в существующей схеме в `frontend/src/App.js` (React Router).

## Стили
- По возможности использовать Tailwind utility-классы и текущие настройки Tailwind.

## API вызовы
- Всегда использовать относительные пути `/api/...`.
- Не хардкодить адреса вида `http://127.0.0.1:5000` в коде.
- Если уже есть helper (например `frontend/src/services/api`), переиспользовать его вместо дублирования `fetch`.
